Notes

This page is served off the homelab box and runs a real Java applet in the browser. No plugin, no JVM install: CheerpJ compiles the Java 8 runtime to WebAssembly and runs the bytecode client side. The applet above sets com.sun.java.swing.plaf.motif.MotifLookAndFeel, so the widgets you see are drawn by Swing's real Motif look and feel, not simulated in CSS.

The page chrome around it is hand written CSS following the same rules: square corners, two pixel bevels, system gray, and no space that is not carrying data.
